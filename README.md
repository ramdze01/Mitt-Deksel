# Mitt Deksel

React + TypeScript + Vite frontend for Mitt Deksel.

Mitt Deksel is a Norwegian website for a physical phone-case machine. Customers visit a machine at a shopping center, choose their phone model, scan a QR code, upload a photo, preview the design, pay at the machine, and receive the printed case in about 3 minutes.

## Run the project

1. Open this folder in VS Code.
2. Open the terminal in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Build

Run `npm run build` to create a production build.
